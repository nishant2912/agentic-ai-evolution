# Interactive Guide to Agentic AI

This repository contains the source code for an interactive, single-page website that explores the world of Agentic AI. The guide is designed to be an educational resource for understanding the fundamental concepts, evolution, and tools related to AI agents.

The live version of the guide can be accessed here: [Link to GitHub Pages once deployed]

## Features

The interactive guide is built as a single-page application with the following sections:

*   **Hero Section:** A brief introduction to the concept of Agentic AI.
*   **AI Agent Basics:** An interactive section that breaks down the core components of an AI agent: Perception, Planning, Action, and Memory.
*   **Plan with an Agent:** A unique, Gemini-powered feature that allows users to input a high-level goal and receive a step-by-step agentic plan.
*   **The Journey to Autonomy:** A timeline that visualizes the conceptual evolution of agentic systems, from Chain-of-Thought reasoning to fully autonomous agents.
*   **LLM Release Timeline:** An interactive timeline and bar chart showcasing the release of major Large Language Models (LLMs) from companies like OpenAI, Google, and Anthropic that have fueled the agentic AI revolution.
*   **The Agentic Developer's Toolkit:** A filterable grid of modern AI-native IDEs, platforms, and tools that are shaping the future of software development.

## Tech Stack

*   **HTML5**
*   **Tailwind CSS:** For styling and layout.
*   **Chart.js:** For the interactive timeline chart.
*   **Google Gemini:** The API powering the "Plan with an Agent" feature.

## How to Use

Simply open the `interactive-guide-with-plugin.html` file in your web browser to explore the guide.

## Publishing to GitHub Pages

This repository is configured to be easily published using GitHub Pages. The `index.html` file automatically redirects to the main `interactive-guide-with-plugin.html` page.
